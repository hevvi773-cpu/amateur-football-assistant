## Football AI Assistant | Full-Stack Developer + Product Designer | Sep 2026 – Present

**GitHub**: github.com/hevvi773-cpu/amateur-football-assistant

An all-in-one management tool for amateur football leagues, covering fixtures, league tables, lineups, card tracking, and meetup coordination, with an AI layer for match predictions, tactical analysis, lineup recommendations, and post-match reviews. **AI-First architecture**: core business runs fully without the LLM; AI is a high-value enhancement layer.

- **Product Design**: Authored PRD V1.1 (To-be design doc, 628 paragraphs), defining three user roles (player / captain / league admin) with permission matrix, four main pages (Home / Lineup / Meetups / Profile), and six AI capabilities (match prediction + tactical guide / lineup recommendation / post-match review / match report / fixture parser)
- **Frontend Implementation**: React 19 + TypeScript + Vite 8 + Tailwind CSS 4 + shadcn/ui (30+ Radix UI components) + ECharts + framer-motion, 124 files, 80+ source files, four pages fully implemented
- **ML Prediction Experiment**: Independently trained and evaluated a match prediction model on 427 raw matches (336 valid samples, 21.1% dropout due to insufficient data), comparing 14 methods (logistic regression / random forest / XGBoost / MLP / Poisson model, etc.), best model training accuracy 76.4%, with confusion matrix, McNemar's test, permutation test, and probability calibration (Brier=0.138 / ECE=0.123)
- **Technical Decision**: Match prediction uses a custom ML model rather than an LLM — prediction tasks require reproducible, well-calibrated, interpretable probability outputs; experiments found LLMs show non-reproducible blind-test results and poor probability calibration, so ML was chosen
- **Honest Limitations**: Experiment report explicitly acknowledges that the three-class model fails to learn draws (few draw samples with indistinct features), extrapolation fails for teams with insufficient head-to-head history, and training accuracy does not represent generalization — no inflated claims

**Tech Stack**: React / TypeScript / Vite / Tailwind CSS / shadcn/ui / ECharts / framer-motion / scikit-learn / FastAPI (designed)
