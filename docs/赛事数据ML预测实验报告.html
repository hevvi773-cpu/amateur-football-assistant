01 数据与方法

完整流程：从原始战报 → 结构化表格 → 球队画像 → 模型预测，全程时间切分验证、严格防数据泄露。

1
战报解析
python-docx 提取 5 份 Word → 正则解析出 427 场：时间、地点、对阵、比分、角球、任意球、定位球、点球、进球人、助攻、扑救、红黄牌。队名/比分覆盖 100%。
2
队名规范化
117 个原始变体名 → 45 个真实队伍（如"计信院/计算机信息科学学院/计算机与信息技术学院"→ 计信）。37 支队伍 ≥10 场，画像样本充足。
3
滚动画像（防泄露核心）
每队每场只累计该场比赛之前的数据：场均进球/失球/净胜球/胜率/角球/任意球/扑救。预测某场比赛时，绝不用到它自己的赛时数据。
4
对称视角
校园足球无主客场意义 → 每场用 md5 固定随机指定视角队，特征 = 双方画像差（A−B），消除"标题左侧队"偏差。336/427 场入样（双方历史≥3场）。
5
模型与验证
逻辑回归（三分类胜/平/负 与 二分类胜/不胜）、随机森林对比；比分用泊松模型（λ=联赛均进球×进攻指数×防守指数，概率矩阵 0–10）。验证：方案A＝2022–25训练→2026外推；方案B＝按时间滚动前80%→后20%。
改进注：md5随机视角虽消除了"左侧队"偏差，但更严谨的做法是双视角扩增（每场同时生成A−B和B−A两个样本）或取特征绝对值，未来改进可采用。

04 样本流失分析（91场被剔除比赛）

入样标准"双方历史≥3场"可能系统性排除最难预测的比赛，需评估对结论的影响。427场总样本中336场入样（78.9%），91场被剔除（21.1%）。被剔除比赛主要是早期比赛和新队伍——这些队伍历史数据不足，恰恰可能是预测难度最高的场景。

错误结构（16 场）与参考性结论

错误 = 10 场"平局被猜成胜负" + 6 场"强弱方向误判"（集中在势均力敌与弱队互啄场次，如教育 vs 园艺园林、马院 vs 电子信息）。

① 大模型盲测 67%（三分类）、80%（方向），略低于机器学习的 74.2% / 90.4%（参考性结论）。机器学习在结构化数值预测上仍有优势；大模型的核心价值在对话交互、解释与内容生成，而非纯数值预测。

② 混合架构的价值不在"预测更准"，在"产品可用"。大模型负责对话、解释、阵容建议、赛后复盘；ML 负责提供可复现、可审计的数值（画像/概率）。预测准确率由数据决定，产品体验由混合架构决定。

③ 关于 RAG 战术知识库：RAG 提升的是内容能力（战术解释、知识问答、建议质量），不会改变预测准确率——比赛结果的预测只由画像数据的信息量决定。战术库与预测模块是平行的两个能力，不是相互增益的关系。

06 结论与建议
  1. 方向预测有效且可靠。历史画像（场均进球/失球/净胜球/胜率）能真实区分强弱：二分类"胜/不胜"准确率 80.6% [69.1–88.5]（外推）/ 82.4% [71.7–89.6]（滚动），比多数类基线高约 38 个百分点，差异经 McNemar 检验显著（p=0.0003）。
  2. 三分类"胜平负"被简单规则封顶，LR与规则无显著差异。LR二分类与规则押胜率在方案A（差异+3.2pp，p=0.753）和方案B（差异+8.8pp，p=0.181）下均无统计显著性差异，两者均显著优于基线。平局占16.1%（10/62，方案A测试集；全336入样场为14.9%）且学不出来，模型与"押胜率高者"规则本质都在判断强弱方向。所有"改进"（近5场窗口、交手史、随机森林、平衡权重）均未稳定超越规则。
  3. 比分能猜，但正确用法是概率分布。单点精确命中 13.1% [6.8–23.7]（方案A），单点精确命中本身难度极高；按概率矩阵猜 Top-3 覆盖率 26.2% [16.9–38.3]、Top-5 覆盖率 39.3% [28.1–51.7]。比分模型顺带的胜平负判断（73.8% [61.7–83.1]）与三分类模型持平，不牺牲方向能力。概率校准方面，Brier=0.138、ECE=0.123，低概率区间存在系统性偏差。
  4. 特征有效性排序（实测）：历史胜率 / 净胜球 / 场均进球（强，与胜率相关 0.95）＞ 场均失球 / 扑救（中）＞ 角球 / 任意球（弱，相关仅 0.15，且 33% 场次缺失）＞ 红黄牌 / 定位球（不可用，记录缺失严重，黄牌仅 33 场）。
  5. 推荐最终形态：一个"滚动画像 + 泊松"混合模型，输出 胜/不胜概率 + 比分概率分布 Top-5，方向判断约 74–80%、Top-5 比分覆盖率约 40%。适合做：球队强弱排行（画像榜）、赛后复盘分析、竞猜式预测。每届打完更新数据即可滚动重训。
  6. 阵容轮换（turnover）的固有局限：校园足球队每年面临毕业轮换，2022–25年的球队画像到2026年可能因核心球员毕业而失效。这是方案A（外推）的固有局限。"近5场窗口反而更差"有两种替代解释：①跨年画像失效（阵容变化导致历史数据不代表当前实力）；②5场窗口样本量太小、噪声过大。当前数据无法区分两者，需更多赛季数据验证。
  7. 样本偏差警示："双方历史≥3场"的入样标准排除了91场（21%）最难预测的比赛，被剔除集规则准确率仅59.3% [49.1–68.9]，比入样集低8.8pp。报告中的精度数字可能高估了真实场景（含新队伍/早期比赛）下的预测能力。
