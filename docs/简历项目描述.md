## 足球 AI 助手 | 全栈开发 + 产品设计 | 2026.09 - 至今

**GitHub**：github.com/hevvi773-cpu/amateur-football-assistant

面向业余足球赛事赛区的一体化管理工具，覆盖赛程、积分榜、阵容、红黄牌、约球等基础业务，并叠加 AI 赛前预测、战术攻略、阵容推荐、赛后复盘等高阶能力。**AI-First 架构**：移除大模型后基础业务仍可完整运行，AI 属于高阶赋能层。

- **产品设计**：独立完成 PRD V1.1（To-be 设计稿，628 段），定义三类用户角色（普通队员/队长/协会人员）与权限矩阵、四个主页面（首页/阵容/约球/个人中心）、六项 AI 能力（比分预测 + 战术攻略/阵容推荐/赛后复盘/赛事纪实/赛程解析）
- **前端实现**：React 19 + TypeScript + Vite 8 + Tailwind CSS 4 + shadcn/ui（Radix UI 30+ 组件）+ ECharts + framer-motion，共 124 个文件、80+ 源文件，四页面完整实现
- **ML 预测实验**：独立完成比分预测模型的训练与评估，427 场原始赛事数据、336 场有效入样（21.1% 样本因数据不足被剔除），对比 14 种方法（逻辑回归/随机森林/XGBoost/MLP/泊松模型等），最优模型训练集准确率 76.4%，含混淆矩阵、McNemar 检验、置换检验、概率校准（Brier=0.138/ECE=0.123）
- **技术决策**：比分预测采用自研 ML 模型而非大模型——预测任务需要可复现、可校准、可解释的概率输出，实验中发现 LLM 盲测不可复现、概率校准差，因此选择 ML 方案
- **诚实的局限性**：实验报告明确承认三分类学不出平局（平局样本少特征不明显）、对历史交锋不足的球队外推失效、训练集准确率不代表泛化能力——不夸大结果

**技术栈**：React / TypeScript / Vite / Tailwind CSS / shadcn/ui / ECharts / framer-motion / scikit-learn / FastAPI（设计中）
